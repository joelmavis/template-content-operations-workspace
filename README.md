# Content Operations Workspace

Plan, create, publish, and improve your content in one local workspace.

## Start

1. Download this repository and open the folder in puppyone Desktop.
2. Choose a configured Agent.
3. Start with one sentence or attach a local file.

- **Plan from a goal:** “Create a seven-day X and Medium content plan for an AI developer tool.”
- **Create from materials:** “Use the product brief and interview notes I attached to draft one Medium article and two X posts.”
- **Review results:** “Import this local performance table and tell me what to repeat or change next week.”

The Agent maintains the calendar, Markdown drafts, publishing status, performance records, and `dashboard.html`. You do not need to create folders, edit CSV files, or run commands.

## Workflow

**Input → Plan → Draft → Track Publishing → Import Results → Review → Update Next Plan**

Open `dashboard.html` to see the current calendar, status mix, recorded performance, and specific next actions. Missing data remains `N/A`; a draft is never treated as published, and a scheduled item does not become published just because time passed.

This template does not automatically post content, access private social dashboards, fetch live metrics, send messages, or invent results. URLs may be stored as publishing or source references, but pasted URLs are not an ingestion mode.

To continue, say “Update this draft’s status,” “Record that this post was published,” or “Review last week’s results.” The Agent reads the existing files before changing anything.
